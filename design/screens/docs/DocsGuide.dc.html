Get started

Your first task

Label an issue, approve a plan, and review the pull request plovi brings back. About ten minutes, most of it waiting.

plovi uses your GitHub CLI sign-in. Run gh auth status to check it before you start.

Label an issue

plovi picks up issues labelled plovi. Start with something small: a bug with clear steps, or a missing test.

terminal
$ gh issue edit 146 --add-label plovi

Within a few minutes the task appears on the board under Planning.

Answer and approve

If the issue leaves something open, a question appears in your Inbox. Once the plan is written, it waits for your approval. Nothing is built until you approve it.

Review the pull request

When checks pass and comments are handled, the task moves to In review and the PR shows up in your Inbox. Review and merge it on GitHub as usual.

What changes for your workflow. The command is now plovi and skills are named plovi-*. The old af command keeps working until 1.0.

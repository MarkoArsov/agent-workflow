## A workflow that belongs to your project

Use Claude Code, Codex, or Cursor. Work in one repository or a folder containing several.
Give an application a task worktree while its unchanged E2E repository supplies checks from its existing checkout.

Setup records your commands, branches, agents, models, and delivery choices. It previews the complete change before writing.

## The runner does the checking

The full flow is **tests → implementation → review → delivery**, with optional stages selected in each plan.
Every stage starts a fresh provider session. The runner checks the actual files and command output before advancing.
A test setup error cannot stand in for a behavioral failure, and a changed diff cannot reuse stale green evidence.

For small changes, use the same skills directly in the [manual lane](tasks.md#choose-a-lane).

## Extend without forking the package

[Copy a skill](customize.md), add a stage, capture a rule, or connect a tracker.
Overrides live with your project and survive package updates. Another project can make different choices.

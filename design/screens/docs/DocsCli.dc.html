CLI

Everything the app does, the CLI does too. Agents use the same commands, so every change passes the same review.

{{c.cmd}}{{c.what}}

plovi take-over <task>

Pauses the task, keeps its slot, and opens an agent session in the task's folder with a brief: the plan, the changes so far, the failed runs and review notes. plovi won't touch the folder until you run plovi hand-back.

--agentclaude, codex or cursor. Defaults to the agent that was working on the task.
--modelModel for the session. Defaults to the stage's model in plovi.toml.
--openStart the session in this terminal instead of printing the command.
terminal
$ plovi take-over 153 --open
Paused #153. Brief written to wt/153/.plovi/brief.md

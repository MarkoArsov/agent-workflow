It asks before it guesses

Questions, plans and reviews land in one inbox, each written so you can decide without opening anything else.

Take over any time

Pause a task and open a briefed agent session in its folder. Hand it back and every check runs again.

One review for every change

Limits, autonomy and agents live in plovi.toml. Changes from the app, the CLI or ⌘K show a diff first.

Start in two commands

Runs on your machine with the agents you already use.

terminal
$ plovi init
$ gh issue edit 146 --add-label plovi

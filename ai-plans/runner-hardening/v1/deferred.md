# Deferred and excluded

- Ledger and full command layer (#18), schedules, containers and isolation backends.
- Enforcement of reserved scheduling/review slots, ready/auto autonomy and grants.
- Actual user-agent configuration, global installation, native settings or profile
  edits; fixtures alone exercise policy/setup/permissions.
- Remote push, PR creation/edit, tracker updates, comments, hosted CI, deployment
  and release operations. PR behavior is tested through a gh double.
- Concurrent writes in one current-checkout or feature-branch repository; the
  supported sharing mechanism is distinct worktrees with non-overlapping claims.
- A general TOML syntax-preserving editing library or arbitrary grant semantics.
- Unrelated model registry updates, catalogue refresh and benchmark/network access.
- Design/token/component changes; use existing documentation components.

The user must approve the complete plan before implementation. A separate request
is required for publishing. Cross-platform CI results and account-authenticated
provider inference cannot be claimed from local fixture results.

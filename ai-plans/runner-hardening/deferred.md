# Deferred and excluded

- Ledger and full command layer (#18), schedules, containers and isolation backends.
- Enforcement of reserved scheduling/review slots, ready/auto autonomy and grants.
- Actual user-agent configuration, global installation and native settings. Only
  this project's explicitly requested checkout-policy change is applied now;
  package setup/defaults/permissions behavior remains fixture-driven implementation.
- Tracker updates, comments, hosted CI, deployment and releases. The revised plan
  selects eventual commit/push/draft-PR delivery, but no remote action is executed
  during specification. Runtime PR behavior is tested through a gh double.
- Concurrent writes in one current-checkout or feature-branch repository; the
  supported sharing mechanism is distinct worktrees with non-overlapping claims.
- A general TOML syntax-preserving editing library or arbitrary grant semantics.
- Unrelated model registry updates, catalogue refresh and benchmark/network access.
- Design/token/component changes; use existing documentation components.

The user must approve the complete plan before implementation. The selected PR delivery follows approval and successful implementation verification. Cross-platform CI results and account-authenticated
provider inference cannot be claimed from local fixture results.

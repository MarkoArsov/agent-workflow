# SidebarNav

The left rail on the window `bg`: project switcher, Ask, four views and one status line.

- The switcher shows the mark and the project; projects are picked there, never listed in the rail.
- `pl-search` opens the command palette (⌘K): ask a question, jump to a task, or change a setting.
- Views, in order: Inbox, Board, Schedules, Settings. Only Inbox shows a count, in `attention`, because each item needs you.
- The footer is one line: a status dot, `Running · 3/4` (agents working / limit), and a pause button.
- Width `sidebar-width`. Under 720px it becomes a sheet behind a menu button.
